# 💰 Personal Finance App

Streamlit-based personal finance tracker for Myanmar Kyats (ကျပ်)။

## ✨ Features

- 💸 **Transactions** — ဝင်ငွေ/ထွက်ငွေ မှတ်တမ်း
- 📊 **Dashboard** — လစဉ် အကျဉ်းချုပ် + recent activity
- 🏦 **Accounts** — Cash, Bank, Wallet balance

## 🛠 Tech Stack

- **Python** 3.12
- **Streamlit** — Web UI
- **SQLite** — Local database
- **pandas** — Data handling

## 🚀 Setup

```cmd
:: ၁. Clone repo
git clone https://github.com/Vas-creator/finance_app.git
cd finance_app

:: ၂. Virtual environment
python -m venv venv
venv\Scripts\activate.bat

:: ၃. Install
pip install -r requirements.txt

:: ၄. Run
streamlit run app.py
```
